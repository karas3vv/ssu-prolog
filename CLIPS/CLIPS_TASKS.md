## Тема 1. Вычисление выражений: b, e, i

**Условие:** в режиме командной строки вычислить значения:

- **b)** `4² + 28 / (5 + 2)`.
- **e)** `max(2³, 3², 2⁵)`.
- **i)** `1.1 · e³ + |cos(√π)| − 4/9`.

Здесь `e` в формуле — число Эйлера, `π` — число пи, углы задаются в радианах. Буква **e)** — также обозначение отдельного пункта в таблице методички.

**Ввод:** не требуется. **Вывод:** значения трёх выражений с подписями `b`, `e`, `i`.

**Файл:** `t1/task_b_e_i.bat`.

## Тема 2. Упорядоченные факты

### №2. Поезда

**Условие:** с помощью `deffacts` создать три упорядоченных факта вида:

```clips
(poezd <номер> <пункт-назначения> <время-отправления>)
```

Добавить два новых факта командой `assert`. Просмотреть список. Удалить факты с индексами 1 и 4. В фактах с индексами 2 и 3 изменить время отправления.

**Что происходит в решении:** исходные поезда загружаются из `t2/task2.clp`; сценарий добавляет ещё два поезда, выводит факты и выполняет изменения. Упорядоченный факт изменяется удалением старого и добавлением нового; новый факт получает новый индекс.

**Ввод:** не требуется. **Вывод:** списки фактов до и после изменений.

### №4. Товары

**Условие:** с помощью `deffacts` создать три упорядоченных факта вида:

```clips
(tovar <наименование> <страна-производитель> <цена> <количество>)
```

Добавить два новых факта через `assert`. Просмотреть список. В фактах с индексами 2 и 4 изменить цену. Удалить все факты.

**Файлы:** `t2/task4.clp` и `t2/task4.bat`.

**Ввод:** не требуется. **Вывод:** списки товаров до и после изменения цен, затем пустой список фактов.

## Тема 3. Неупорядоченные факты: №1

### Часть А. Создать, изменить и сохранить клиентов

**Условие:** создать файл с тремя шаблонными фактами вида:

```clips
(client (name <фамилия>) (in <индивидуальный-номер>) (citi <город>))
```

Для слота `citi` задать значение по умолчанию. Загрузить факты. У факта №1 изменить город, у №2 — фамилию. Продублировать факт №3, изменив индивидуальный номер `in`. Сохранить полученный список в файл.

**В решении:** город по умолчанию — `Samara`, результат записывается в `t3/clients_a.fct`.

### Часть Б. Загрузить и дополнить клиентов

**Условие:** загрузить сохранённый список. Добавить два новых факта через `assert`. Удалить факты с индексами 1 и 3. Просмотреть результат и сохранить его в другой файл.

**В решении:** читается `t3/clients_a.fct`, результат записывается в `t3/clients_b.fct`.

**Порядок запуска:** сначала `task1_a.bat`, потом `task1_b.bat`. Оба сценария используют шаблон из `t3/task1.clp`.

**Ввод:** не требуется. **Вывод:** промежуточные списки фактов и два файла `.fct`.

## Тема 4. Правила: №2 — товары

**Условие:** через `deffacts` создать пять упорядоченных фактов:

```clips
(tovar <наименование> <цена> <количество> <год-производства> <страна>)
```

Определить правила:

1. Если товар выпущен **до 2010 года ИЛИ его количество меньше 4**, добавить `(ucenka <наименование> <сумма-уценки>)`. Сумма уценки — **15% цены**.
2. Для **импортных товаров текущего года** добавить `(nacenka <наименование> <сумма-наценки>)`. Сумма наценки — **7% цены**.
3. Вывести сообщение о том, есть ли в базе товары российского производства.

В фактах `ucenka` и `nacenka` хранится **размер изменения цены**, а не итоговая цена товара.

**В решении:** текущий год задан глобальной переменной `?*current-year* = 2026`, Россия обозначена символом `Russia`.

**Ввод:** не требуется. **Вывод:** сообщение о российских товарах и список фактов с рассчитанными уценками и наценками.

**Файлы:** `t4/task2.clp`, `t4/task2.bat`.

## Тема 5. Процедурные функции

### №2. Список сотрудников

**Условие:** создать правило `spisok_sotr`, которое запрашивает количество сотрудников, вводит ФИО и должность каждого и добавляет факты:

**Ввод:** сначала неотрицательное целое количество сотрудников, затем ФИО и должность каждого. Текст с пробелами вводить **в двойных кавычках**.

**Пример ввода по запросам:**

```text

"Петров Пётр Петрович"

```

**Вывод:** список фактов о сотрудниках. **Файл:** `t5/task2.clp`.

### №4. Сумма

**Условие:** создать правило для вычисления:

```text
S = 1/2² + 1/4² + 1/6² + … + 1/(2n)²
```

**Ввод:** положительное целое `n` — количество слагаемых. **Вывод:** `S`.

**Пример:** `n = 2` → `S = 0.3125`. **Файл:** `t5/task4.clp`.

### №6. Наибольший общий делитель

**Условие:** создать правило `nod` для нахождения НОД двух натуральных чисел. Использовать алгоритм Евклида с вычитанием: пока числа не равны, заменять большее разностью большего и меньшего. Когда числа сравняются, любое из них равно НОД.

**Ввод:** два положительных целых числа, каждое после своего запроса.

**Пример:** `24`, `18` → `GCD = 6`. **Файл:** `t5/task6.clp`.

## Тема 6. Функции пользователя

### №1. Длина отрезка и периметр треугольника

**Условие:** создать функцию длины отрезка по координатам его концов:

```text
D = √((x₂ − x₁)² + (y₂ − y₁)²)
```

Используя эту функцию, найти периметр треугольника по координатам трёх вершин:

```text
P = AB + BC + CA
```

**Ввод:** шесть чисел, по одному на запрос: `xA`, `yA`, `xB`, `yB`, `xC`, `yC`.

**Пример:** `0`, `0`, `3`, `0`, `0`, `4` → `P = 12`.

**Функции в решении:** `segment-length`, `triangle-perimeter`. **Файл:** `t6/task1.clp`.

### №4. Кусочная функция с параметром a

**Условие по изображению в методичке:** определить функцию `Y = f(x)` с выбором формулы:

```text
        |x − a| / x²,  если x < 0;
Y =     0,             если x = 0;
        sin(|x + a|),  если x > 0.
```

**Ввод:** сначала `x`, затем `a`. **Вывод:** `Y`.

**Соответствие методичке:** в `t6/task4.clp` положительная ветвь исправлена на `sin(|x + a|)`. Например, при `x = 1`, `a = −2` получается `sin(1) ≈ 0.84147`.

**Функция в решении:** `piecewise-y`. **Файл:** `t6/task4.clp`.

### №8. Рекурсивная сумма

**Условие:** создать рекурсивную функцию для вычисления:

```text
S(n) = 1/1² + 1/2² + … + 1/n²
```

**Рекуррентная формула:** `S(0) = 0`; при `n > 0`: `S(n) = S(n − 1) + 1/n²`.

**Ввод:** неотрицательное целое `n`. **Пример:** `n = 2` → `S = 1.25`.

**Функция в решении:** `sum-inverse-squares`. **Файл:** `t6/task8.clp`.

## Тема 7. Обработка строк

В этих задачах строки вводятся **без кавычек**, каждая на отдельной строке.

### №1. Замена символа

**Условие:** создать правило, заменяющее в строке указанный символ другим.

**В решении:** заменяются все вхождения. Введите исходную строку, заменяемый символ, новый символ. В двух последних строках должно быть ровно по одному символу.

**Пример:** `banana`, `a`, `o` → `bonono`. **Файл:** `t7/task1.clp`.

### №3. Удаление подстроки

**Условие:** создать правило, удаляющее из заданной строки все вхождения указанной подстроки.

**Ввод:** исходная строка и непустая удаляемая подстрока.

**Пример:** `banana`, `na` → `ba`.

**Особенность решения:** поиск повторяется в изменённой строке до полного отсутствия подстроки; пустая подстрока отклоняется. **Файл:** `t7/task3.clp`.

### №5. Удаление лишних пробелов

**Условие:** создать функцию, удаляющую лишние пробелы и оставляющую по одному между словами.

**В решении:** также убираются пробелы в начале и конце. Обрабатывается обычный пробел, а не табуляция.

**Пример:** `  hello   world  ` → `hello world`.

**Ввод:** одна строка. **Функция:** `normalize-spaces`. **Файл:** `t7/task5.clp`.

## Экспертная система «Вид спорта»

**Задача выбранной спортивной системы:** в диалоге определить загаданный вид спорта по его признакам. Основа — ваша программа на Прологе `t7/task1.pl`.

Система должна задавать вопросы с ответами «да/нет», запоминать ответы, не повторять вопросы, вывести один распознанный вид спорта с объяснением либо сообщить, что подходящего варианта нет.

**База знаний: 20 видов спорта.** Футбол, баскетбол, волейбол, гандбол, водное поло, регби, теннис, настольный теннис, бадминтон, хоккей с шайбой, фигурное катание, лыжные гонки, биатлон, сноуборд, бокс, дзюдо, фехтование, плавание, прыжки в воду, велоспорт.

**Ввод:** `да` / `нет` или `yes` / `no`, без точки. `stop` завершает консультацию.

**Пример:** «командная игра с мячом?» → `да`; «мяч в основном передают и бьют ногами?» → `да`; результат — футбол.

**Файлы:** `sport_expert/sport_expert.clp`, `sport_expert/run.bat`, `sport_expert/README.md`, `sport_expert/REPORT.md`.

В отдельной методичке `metod_proek_ES v Clips.doc` предложены системы про принтер и плеер. Спорт — выбранная вами тема, реализованная по тому же принципу; отдельного спортивного задания в методичках нет.

## Команды, которые могут понадобиться

| Команда | Назначение |
|---|---|
| `(facts)` | Показать текущие факты |
| `(rules)` | Показать список правил |
| `(reset)` | Восстановить начальное состояние текущей программы |
| `(run)` | Выполнить правила |
| `(clear)` | Удалить загруженные определения и факты |
| `(exit)` | Выйти из CLIPS |

Для повторного запуска задач тем 5–7 и экспертной системы выполните `(reset)`, затем `(run)`. Для тем 1–4 удобнее заново выполнить соответствующий `(batch "...")`.

Расширение `.clp` используется для определений программы, `.bat` — для последовательности команд CLIPS, `.fct` — для сохранённых фактов. `.bat` из этого проекта запускаются внутри CLIPS, а не в оболочке операционной системы.
